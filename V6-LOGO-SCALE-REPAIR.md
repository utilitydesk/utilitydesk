## Change
Increased the shared UtilityDesk horizontal logo across the entire site.

## Desktop
- Logo height: 54px

## Mobile
- Logo height: 46px

## Scope
This is a shared CSS architecture change and therefore applies to all
calculators, PDF tools, HR Suite pages, document generators, blog pages,
utility pages, legal pages, and the home page that use the canonical
`ud-brand-logo` header component.

No individual page HTML was modified.
