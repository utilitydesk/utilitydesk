What Is a Percentage Decrease Calculator?

A Percentage Decrease Calculator computes the percentage decrease between an original value and a new value. It shows both the absolute decrease and the percentage decrease, along with the multiplier.

This calculator is useful for calculating discounts, price reductions, depreciation, population decline, and any scenario where you need to measure how much a value has decreased.

Percentage Decrease Formula

Absolute Decrease = Original Value - New Value
Percentage Decrease = (Absolute Decrease / Original Value) × 100
Multiplier = New Value / Original Value
Absolute = Actual differencePercentage = Relative changeMultiplier = Factor of decrease

Frequently Asked Questions

How to calculate percentage decrease?
Percentage Decrease = ((Original Value - New Value) / Original Value) × 100. For example, if a price decreased from 200 to 150: ((200-150)/200) × 100 = 25% decrease.
What is the difference between absolute and percentage decrease?
Absolute decrease is the actual difference (Original - New). Percentage decrease is the relative change expressed as a percentage. For example, 200 to 150: absolute = 50, percentage = 25%.
How to calculate discount percentage?
Discount % = ((Original Price - Sale Price) / Original Price) × 100. For example, if original price is 1000 and sale price is 800: ((1000-800)/1000) × 100 = 20% discount.
Can percentage decrease be more than 100%?
No, percentage decrease cannot exceed 100% because the new value cannot be negative. A 100% decrease means the value became zero.
How to reverse a percentage decrease?
To find original value after X% decrease: Original = New / (1 - X/100). For example, if price after 20% decrease is 80: Original = 80 / 0.80 = 100.
